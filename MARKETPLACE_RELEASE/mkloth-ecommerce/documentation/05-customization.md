# 05. Customization

Everything below is aimed at rebranding and retuning the store for your own
shop. All changes here are safe and localized — no deep logic is affected.

## Branding

| What | Where |
| --- | --- |
| Brand name + Urdu wordmark | `src/lib/constants.ts` (`BRAND_NAME`, `BRAND_WORDMARK_UR`) |
| Logo image | `public/logo-clean.png` — the logo used by the `BrandLogo` component |
| Footer / navbar copy | `src/components/layout/footer.tsx`, `navbar.tsx` |
| Page metadata (title, description) | `src/app/(store)/layout.tsx` and each page's `export const metadata` |
| Site tagline / hero copy | Home page components in `src/components/home/` (hero, marquee, promo) |
| Favicon / icons | `src/app/icon.svg` (the "M" monogram favicon) |

> The header, footer, and favicon use a clean text-based "MKloth" wordmark
> defined in `src/components/layout/brand-logo.tsx` and the brand constant
> `BRAND_NAME` in `src/lib/constants.ts`. To use your own image logo, update that
> component and the favicon/icon references before going live.

## Theme (colors, fonts)

- Theme tokens (background, foreground, the signature lime accent
  `--color-accent: #e2f03d`, etc.) are defined as CSS variables in
  `src/app/globals.css`, split into light and dark.
- Fonts load through `next/font/google` in the root layout (`local/Fira Sans`
  style). Swap the font families there; the base UI is weight-driven, so most
  serif/sans choices sit fine.
- `components.json` maps the shadcn/ui-style preset if you want to regenerate
  primitives.

## Content

- **Demo product images** are original local SVG concept artworks generated by
  `scripts/generate-product-images.mjs` into `public/images/` (seeded at
  `db:seed`). Replace product images through the admin panel — uploads are
  saved to `public/uploads` and survive re-seeding. The `PLACEHOLDER_IMAGE`
  constant in `src/lib/constants.ts` is the fallback for any product without
  images.
- **Categories** (3 by default) ship as constants for the seed and are editable
  in the admin panel. Home page "Shop by Style" mirrors the same three slugs
  from the `CATEGORIES` constant to keep them consistent.
- **Products sold out:** products with `inStock = false` show a "Sold Out"
  state and cannot be added to the cart.

## Business rules

See 02-configuration for `DELIVERY_FEE`, `FREE_DELIVERY_THRESHOLD`,
`SIZE_OPTIONS`, `COLOR_OPTIONS`, and `ORDER_STATUSES` in
`src/lib/constants.ts`, and `formatPrice` in `src/lib/utils.ts` for currency
formatting (prices are integer USD).

## Optional Google login

Enabled by setting all four `SUPABASE_*` variables (see 02-configuration). If
you do not use it, the buttons are automatically hidden — no code change needed.

## Rotating the default admin password

After seeding, either:

- Set `SEED_ADMIN_PASSWORD` in `.env` before running `db:seed`, or
- Log in as admin, then update via the database (`prisma` / a SQLite tool)
  using a bcrypt hash of your new password

> The `db:seed` script upserts the admin account but never resets an existing
> password (`update: {}`), so a user-rotated password is safe from re-seeding.
